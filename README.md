# JRA-AI v3.2.1 — テキスト入力完成版

スマホでコピーした競馬情報を貼り付けて予想を作成する、React + TypeScript + Vite製のJRA予想ツールです。

## 入力方式

スクリーンショット・OCRは使用しません。次の6種類のテキストを、用意できたものだけ貼り付けます。

- 出馬表
- タイム指数（標準）
- タイム指数（近5走）
- AI展開予測
- 厩舎コメント
- 調教評価

「テキストを一括反映」を押すと、馬番を中心に各情報を統合します。取り込み後は表で修正できます。

## 調教評価

`S / A / B / C / D`、または `◎ / ○ / ▲ / △ / ×` に対応します。
文章では「抜群」「良好」「順調」「一息」「不振」なども評価へ変換します。

例:

```text
1 セイリュウ A
2 コスモルトチェコ B
3 エレガントステップ S
```

## 保存と結果入力

1. テキスト解析後に「レースを保存」
2. 保存済みレース一覧から対象レースを呼び出す
3. レース終了後に「結果を入力」
4. 着順を入力して「結果保存・学習」

予想保存と結果入力は分離されています。

## 開発

```bash
npm install
npm run dev
npm run build
```

VercelではViteプロジェクトとしてそのままデプロイできます。

- 馬番・馬名・短評・矢印・追い切り時計が連続する調教欄を馬ごとのブロックとして解析します。
- 短評と矢印を主軸に、遅れ・好気配・良化などの記述を補助評価し、S〜Dへ変換します。
