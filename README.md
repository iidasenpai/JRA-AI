# JRA-AI Ver.1.0

スマホ向け中央競馬予想ツールです。

## 主な機能

- 出馬表・タイム指数・近5走・AI展開・厩舎コメントのスクリーンショットOCR
- 馬名、指数、人気、オッズ等の自動入力
- タイム指数、展開、調教、適性、オッズを使った総合評価
- ◎○▲△☆の自動付与
- レース結果の入力と簡易学習
- ブラウザ内への自動保存

## GitHubへアップする方法

このZIPを展開し、中のファイルとフォルダをすべてリポジトリ直下へアップロードしてください。

## Vercel

GitHubリポジトリをVercelへImportしてください。通常は設定変更なしでデプロイできます。

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

## 注意

OCRにはブラウザ上でTesseract.jsを使用します。初回解析時はOCRライブラリと言語データの読み込みがあるため、通信環境によって時間がかかります。画像認識結果は必ず確認し、誤読箇所を修正してください。
