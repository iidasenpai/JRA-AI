# JRA-AI v3.9.0 — 詳細出馬表・脚質/適性自動取込版

スマホでコピーした競馬情報を貼り付けて予想を作成する、React + TypeScript + Vite製のJRA予想ツールです。

## 入力方式

スクリーンショット・OCRは使用しません。次の6種類のテキストを、用意できたものだけ貼り付けます。

- 出馬表
- タイム指数（標準）
- タイム指数（近5走）
- AI展開予測
- 厩舎コメント
- 調教評価

「テキストを一括反映」を押すと、馬番を中心に各情報を統合します。取り込み後は表で修正できます。

## 調教評価

`S / A / B / C / D`、または `◎ / ○ / ▲ / △ / ×` に対応します。
文章では「抜群」「良好」「順調」「一息」「不振」なども評価へ変換します。

例:

```text
1 セイリュウ A
2 コスモルトチェコ B
3 エレガントステップ S
```

## 保存と結果入力

1. テキスト解析後に「レースを保存」
2. 保存済みレース一覧から対象レースを呼び出す
3. レース終了後に「結果を入力」
4. 着順を入力して「結果保存・学習」

予想保存と結果入力は分離されています。

## 開発

```bash
npm install
npm run dev
npm run build
```

VercelではViteプロジェクトとしてそのままデプロイできます。

## v3.8.0 — 160R検証ベースの本命精度改善
- 厩舎コメントの誤紐付けを自動検出。コメント先頭の馬名が現在の馬と違う場合、同レース内なら正しい馬へ移し、別レース由来なら破棄して中立化します。
- 調教・コメント・状態の学習係数に安全上限を追加し、誤データや短期偏りの増幅を抑えます。
- `value` 学習値を本命選定に反映。人気順のコピーにはせず最大約2点の市場補正だけを使い、人気薄の高指数馬を◎に上げすぎる傾向を抑えます。
- 能力指数そのものと、本命選定用のスコアを分離しました。
- 「◎敗因分析」を追加し、外れた◎と実際の勝ち馬の指数差を集計できます。
- 条件別成績は10R未満を参考値として明示し、少数サンプルで条件補正を暴走させない方針にしました。
- 既存保存レースは削除しません。同じGitHub Pages URLへ更新すればIndexedDBの保存データをそのまま引き継ぎます。
