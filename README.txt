【結果ファイルを受け取ったら：iPhone】
1. 結果のJSONを「ファイル」に保存。
2. アプリの「結果ファイルを読み込む」でJSONを選ぶ。
3. 反映可能・反映済み・要確認の件数と、各レースの理由を確認。
4. 「結果を反映する」を押す。
保存済みレースの着順と払戻が更新され、AI回顧と学習を再構築します。
保存済みレースの「取得した結果・払戻」を開くと全頭着順と払戻を見られます。
同じファイルを繰り返し読んでも、学習の件数は増えません。

【照合条件】
開催日・競馬場・R、芝ダ・距離、全頭の馬番・馬名が一致する保存レースだけ対象。
取得元IDが保存されている場合は、そのIDも照合します。
保存予想の印・点数・固定日時はそのまま保持します。
一致しないレース、重複記録、保存済みと異なる着順・払戻は反映しません。
確定前・同着の結果は、この形式では自動反映の対象にしません。
払戻未取得の結果も読み込めます。払戻を取得できた後に追記できます。
購入額を記録していないため、払戻の取り込みだけで回収率は計算しません。
結果を手動で訂正して着順が変わると、古い払戻を表示対象から外し履歴に残します。

このZIPは機能の更新用で、実際の新しい結果データは入っていません。
次回からレース終了後に「対象日の結果をまとめて」と依頼してください。
取得・照合できた確定結果を結果用JSONにまとめます。
新しいサーバーの契約や追加の月額サービスは不要です。
