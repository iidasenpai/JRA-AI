【iPhoneでの使い方】
1. いまのアプリで「全データ保存」を押してバックアップを残す。
2. 上記4ファイルをGitHubへ反映し、サイトの更新完了後にアプリを再読み込み。
3. 表示がv3.13.6になったことを確認。
4. 「取得データを読み込む」で、受け取った全レースJSONを選ぶ。
5. 「全35レースを一括保存」を1回押す（件数は読み込んだファイルに応じて変わる）。
6. 「一括保存 ○件／保存済み等 ○件」を確認。保存済み一覧から各レースを開けます。
すでに取得データを読み込んである場合は、4の操作は不要です。

【保存の扱い】
・現在の画面の重み・学習係数・人気オッズ設定で全レースを個別計算します。
・保存済みの同じ開催日・競馬場・Rは、未確定・結果済みとも上書きしません。
・複数回押しても、同じレースを追加しません。
・新馬など指数不足のレースは評価保留のまま保存します。◎は作りません。
・発走後でも参考保存できます。保存日時は実際の操作時刻とし、発走前の検証実績には加えません。
・入力中のレースや未保存の編集は、そのまま残ります。
・予想計算式は変えていません。展開図はレースを開いたときに再計算します（一括保存では展開図スナップショットを作成しません）。
