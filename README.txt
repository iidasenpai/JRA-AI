【iPhoneでの使い方】
1. 取得データのJSONを「ファイル」に保存。
2. アプリの「取得データを読み込む」でJSONを選ぶ。
3. 複数レースの場合、一覧から選び「選んだレースを開く」。
4. 予想を確認して「レースを保存」。別レースは再び一覧から選ぶ。
一覧は同じブラウザ・同じサイトの端末内に保存されます。
今までの1レース用ファイルも読み込めます。

このZIPはアプリ更新用です。新たな全レース取得データは入っていません。
次回から、依頼された対象日のデータを取得・照合できた範囲でまとめます。
有料ページのログイン切れ・未公開・未対応ページ等は取得完了と扱いません。
オッズ・馬体重・馬場は取得時点の情報で、自動更新はしません。
ファイルを読み込んだだけでは、全レースの予想保存は行いません。
既存の予想・結果・学習履歴は上書きしません。
サーバー契約や新たな月額サービスの申込みは不要です。
