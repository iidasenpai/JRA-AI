JRA-AI v3.13.1 自動取得の1レース試験

確認できたこと
2026年10月17日 新潟1R（2歳未勝利・芝1600m・09:45・12頭）について、
netkeibaの出馬表／AI展開／詳細／標準指数／近5走、競馬ブックの調教／厩舎コメントを取得。
馬番・馬名・開催日・競馬場・R・芝ダ・距離を照合し、アプリの予想入力へ変換できた。
実データの読み込みと予想保存までDOM環境で検証済み。既存322件を保持し、323件目が結果待ちとして追加されることを確認。

重要：このZIPを反映しただけで常時自動取得が始まるわけではありません。
「1レース分を取得して、正しくアプリへ渡せる」ことを実証した試作です。
常時サーバー・認証の保持・定期実行・アプリへの自動配信・確定結果の自動取得は未接続です。
この会話のブラウザーのログイン状態は、別の取得サーバーへ移していません。

適用するファイル（GitHubへ入れるもの）
src/内の5ファイルを既存src/へ追加・差し替え。
package.json、package-lock.jsonをリポジトリの一番上へ差し替え。
同梱のscripts/、tests/は検証用。アプリ実行に必須ではありません。
この試作は現在反映済みのv3.13.0を基にしています。

試験データの読み込み
1. アプリの「全データ保存」で現在のデータを退避。
2. 上記コードを反映したアプリを開く。
3. 「取得データを読み込む」を押す。
4. 「アプリで読み込む」フォルダ内のJSONを選ぶ。
5. 新潟1R・12頭・発走日時などが入ったことを確認し、「レースを保存」。

「アプリで読み込む」のJSONはGitHubへアップロードしません。
このJSONは全データバックアップではありません。「全データ読込」ではなく、新しい「取得データを読み込む」から使います。
指数・調教・コメントは取得時点の情報です。馬体重は未発表のため空欄。過去走の馬体重は転用していません。
試験データには既存の予想・学習履歴は含まれず、現在の履歴を置き換えません。

保護処理
・ログイン切れで見本1頭だけの場合、完全データとして取り込まない。
・6ページの頭数、馬番、馬名が揃わない場合は停止。
・レースID、開催日、場、R、芝ダ、距離が食い違う場合は停止。
・非表示の文字列ではなく、画面に表示される文字を用いる。
・異常な指数値、コメントと馬名の不一致、未取得の入力を拒否。
・未発表の馬体重を増減ゼロとして補完しない。
・コメント由来の状態補完には推定フラグを付け、二重加点を抑える。

今回取得した実データと欠損・取り違えの変異テスト16項目合格。
TypeScript検査・Vite本番ビルド成功。

本番サイトへの反映はユーザー側で必要。常時自動運転はまだ未設定。
