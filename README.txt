JRA-AI v3.13.0 修正ファイル一式

適用方法
1. 現在のアプリで「全データ保存」を行い、元データを退避してください。
2. ZIP内の src フォルダの4ファイル、package.json、package-lock.jsonを、アプリ本体の同じ場所へ追加・差し替えます。
   src/JRAPredictionTool.tsx は差し替え、src/integrity.ts・src/prediction.ts・src/learning.ts は追加です。
3. 従来と同じ手順でビルド・反映してください（npm install / npm run build）。
4. 同じURLで開くと、既存保存データを検査し、予想を保持して学習・回顧を組み直します。
5. 手元のデータが添付時と同じ322件なら、data/jra-ai-repaired-backup-2026-10-16.json を「全データ読込」で復元することもできます。
   添付後に新しいレースを追加した場合は、この修復済みJSONで置き換えず、アプリ起動時の自動修復を使ってください。

通常利用
・新規保存には開催日とRを入力します。
・発走日時は日本時間で入力します。発走前に固定保存し、発走後に結果を登録したものを「事前固定の検証」として区別します。
・発走日時なしの予想、古い記録は、事前検証済みの実績にはしません。
・結果訂正は保存済みレースの「結果を修正」から行います。予想は変えず、学習を最初から再構築します。
・「新しい評価方式を検証する」は初期OFFです。新方式の優位性が確認できていないためです。

確認待ち
札幌11R・芝1200mで、同じ出走馬に結果10-13-2／3-11-5が登録された2件は、削除せず学習・成績から除外します。
正しい開催日・出馬表・結果を確認し、誤記録を修正または削除してください。開催日・Rの訂正機能も用意しています。
同じ出走馬の矛盾記録が未解決のままなら、両方を除外し続けます。

同梱
src/、package*.json : 適用対象
 tests/ : 回帰テスト（npm test）
 scripts/validate-backup.mjs : バックアップ移行・時系列比較の再現用
 data/ : 修復済みバックアップ・詳細検証結果（アプリのsrcには入れません）
 検証と変更点.md : 作業内容と制限
